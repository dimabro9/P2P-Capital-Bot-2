# P2P Capital — deployment package

В этом архиве сохранён текущий бот и добавлена конфигурация `systemd` для Linux VPS.

- Режим бота: aiogram 3 + Telegram Long Polling.
- Python: рекомендуется 3.12.
- Единственная переменная окружения приложения: `BOT_TOKEN`.
- Админ ID, Premium Emoji IDs и прочие настройки остаются в `bot.py`.
- Для Ubuntu инструкция: `deploy/README-UBUNTU.md`.

Важно: код сам по себе не может обеспечить круглосуточную работу на бесплатном Render Web Service. Бесплатный Render Web Service засыпает после 15 минут без входящего трафика, а Background Worker не относится к бесплатным типам сервисов. Для постоянно работающего polling-бота нужен VPS/сервер, который остаётся включённым. Oracle Cloud описывает Always Free VM, но оставляет за собой право reclaim idle instances при выполнении условий простоя; это не безусловная гарантия 24/7. Проверьте условия хостинга перед переносом.
